# Lead Intake to CRM · browser demo

Static, browser-only version of the same rules (normalise, de-duplicate, score, review routing) on the same 24
synthetic leads. The full n8n + FastAPI version is at https://github.com/anggittaba/lead-intake-crm.
`tests/test_web_demo.py` in that repo checks that this engine gives exactly the same results as the Python one.
