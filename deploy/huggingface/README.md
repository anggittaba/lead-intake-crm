Online demo of Lead Intake to CRM. Press **Run demo** to push 24 synthetic leads through the pipeline.
To publish: create a Docker Space, copy this file to the Space root as `README.md`, and push the repo's
`Dockerfile`, `requirements.txt`, `leadcrm/` and `data/`. No secrets are needed; without tokens, notifications are simulated.
